AI Phishing Awareness Campaign Kit

📌 Project Overview

The AI Phishing Awareness Campaign Kit is an educational cybersecurity project designed to help students and internet users identify phishing attacks and stay safe online.

Phishing is a cyberattack in which attackers use fake emails, messages, or websites to trick people into revealing sensitive information.

🎯 Objectives

- Understand what phishing is.
- Identify common warning signs of phishing attacks.
- Learn safe internet practices.
- Improve cybersecurity awareness among students.
- Test knowledge through an interactive quiz.

✨ Features

- Simple and user-friendly website.
- Information about phishing attacks.
- Common phishing warning signs.
- Tips to stay safe online.
- Interactive knowledge-check quiz.
- Educational campaign materials.

🛠️ Technologies Used

- HTML – Website structure.
- CSS – Website design and styling.
- JavaScript – Interactive quiz functionality.
- GitHub – Project storage and sharing.

📂 Project Files

- "index.html" – Main webpage.
- "style.css" – Website styling.
- "script.js" – Interactive quiz.
- "README.md" – Project documentation.

🚨 Common Warning Signs of Phishing

1. Messages that create a sense of urgency.
2. Suspicious links and attachments.
3. Requests for passwords or OTPs.
4. Unknown or unusual sender addresses.
5. Unexpected requests for money or personal information.

🔐 Safety Tips

- Think before clicking links.
- Verify the sender before responding.
- Never share passwords or OTPs.
- Use multi-factor authentication.
- Report suspicious emails and messages.

▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Explore the educational content and try the quiz.
